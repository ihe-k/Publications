# Carbon Monoxide Incidents in the UK (2012–2024)

This repository contains data analysis related to carbon monoxide (CO) incidents in the United Kingdom from 2012 to 2024.

Key Highlights

* Analysis of incident trends over time
* Breakdown by dwelling type, cause and severity
* Geographical distribution insights
* Recommendations for public health interventions

For a detailed overview and findings, please refer to the official publication:

[Carbon Monoxide Incidents, 2012 to 2023](https://www.gov.uk/government/statistics/carbon-monoxide-incidents-2012-to-2023)
